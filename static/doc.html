📦 工厂进销存管理系统 — 使用说明

一、登录

打开系统网址，输入用户名和密码。

默认管理员：admin / admin123（首次登录后建议修改密码）。

二、首页

顶部四张统计卡片：今日出库金额、今日入库数量、本月销售额、低库存预警。点击卡片可跳转对应页面。

快捷操作按钮可快速跳转到常用功能。

三、每日录入

日常出入库在这里录入。

快速填写（推荐）

  1. 选择 出库/入库
  2. 选择 销售人（下拉框）
  3. 点击 规格 → 点击 颜色 → 自动新增一行
  4. 填写数量和单价
  5. 点击 ✔ 提交录入

手动添加

点击「+ 出库行」或「+ 入库行」，手动输入规格、颜色等信息。

撤销误操作

下方「今日已录入」表格，点击 ✕ 撤销 可删除错误记录并自动恢复库存。

四、实时库存

查看所有规格+颜色的当前库存，搜索框可筛选规格。

点击库存数字可查看最近变动历史。

点击 📥 下载快照 导出带水印的库存 HTML。

五、出库 / 入库记录

按人员/年月查询出库或入库明细，支持导出 Excel。

六、预警阈值

全局默认阈值：低于此值触发低库存预警。

各规格颜色阈值管理：可为每个规格+颜色单独设置阈值，留空使用全局默认值。

库存低于阈值的行会红色高亮。

七、销售汇总

选择年月查询销售额，按人员和品类分别统计。

底部合计行显示总销售额。

八、数据分析

选择月份查看三个图表：

  • 📅 每日销售额折线图
  • 👤 销售人员柱状图
  • 📦 产品规格饼图

九、基础数据

模块功能
📋 规格管理添加/修改/删除产品规格（有库存的不可删）
🎨 颜色管理添加/修改/删除颜色（有库存的不可删）
👥 销售人员添加/删除销售人员
📥 库存导入上传 Excel 批量导入库存

十、财务管理

功能说明
📋 报账访问 /static/report.html，微信可用
💰 管理查看/筛选/导出/撤销财务记录
📂 类别添加/删除财务类别
初始余额访问 /static/init-balance.html，密钥 上山打老虎

余额公式：期初余额 + 收入 − 支出

十一、管理员

仅超级管理员可见。可添加/删除管理员、重置密码、查看操作日志。

十二、快捷链接

功能地址
报账提交/static/report.html
初始化余额/static/init-balance.html
库存更新（Excel上传）/static/upload.html
⚠️ 以上三个页面为独立入口，其中「库存更新」和「初始化余额」需要密钥：上山打老虎

十三、服务器运维

  • 更新代码并重启：./restart.sh
  • 数据库备份：每天凌晨 2 点自动备份到 backups/ 目录，保留 30 天
  • 手动备份：./backup.sh
