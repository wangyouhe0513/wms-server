📦 工厂进销存管理系统 — 使用说明

一、登录与安装

打开系统网址，输入用户名和密码。默认管理员：admin / admin123

登录有效期：登录状态保持 24 小时，超时自动退出，需重新登录。

手机安装到桌面：安卓浏览器自动弹窗「添加到桌面」；苹果 Safari 打开 → 分享 → 添加到主屏幕。安装后全屏打开就像原生 App。

刷新页面：手机在顶部往下拉即可下拉刷新。

二、首页仪表盘新

八张统计卡片，分上下两排：

卡片说明
📤 今日出库 / 📥 今日入库当日出库、入库件数
💰 今日销售当日销售额（金额默认隐藏为 ***，点击才显示）
🔴 低库存预警低于阈值的 SKU 数量
📤 本月出库 / 📥 本月入库本月累计出库、入库件数
💰 本月销售本月累计销售额（同样默认隐藏）
💵 当前余额财务当前余额（默认隐藏）

金额隐私：涉及金额的数字默认显示 ***，点击卡片即可切换显示/隐藏，防止他人窥屏。

下方有低库存预警列表（点击跳转库存）、系统信息条（规格/颜色/工人/工序/本月工资金额）。

页面背景带当前登录用户名的水印，防止截图外泄。

三、每日录入

快速填写（推荐）

  1. 选择 出库/入库 → 选择 销售人 → 点击 规格 → 点击 颜色 → 自动新增一行
  2. 填写数量，点击 📋 一键填价 自动按历史价格匹配单价
  3. 点击 ✔ 提交录入

一键填价规则新

按以下优先级自动匹配单价：① 该销售人该规格的最近历史价 → ② 该销售人该产品的历史价 → ③ 该规格的最近售价。找不到时留空手动填。

防重复录入

同一销售人 + 规格 + 颜色 + 数量，当天已录入过则禁止重复提交。

撤销误操作

下方「今日已录入」表格，点击 ✕ 撤销 可删除错误记录并自动恢复库存。

四、实时库存 + 盘点调整新

查看所有规格+颜色的当前库存，搜索框可筛选；点击库存数字查看最近变动历史。

库存盘点 / 调整

  1. 在库存表每一行点 🔧 调整
  2. 输入实际盘点数量和调整原因（如：月末盘点、录入错误等）
  3. 点 ✅ 确认调整，系统自动计算差异（盘盈/盘亏）并记录

调整记录

库存页下方「📋 调整记录」按年月查看所有调整历史，顶部汇总显示盘盈 / 盘亏 / 净差异件数。

点 📥 下载快照 导出带水印的库存文件。

五、出库 / 入库记录新

按人员、规格、颜色、年月多条件筛选，列表按日期倒序（最新在前）。

数据超过 30 条自动分页，底部可翻页并显示页码；支持导出 Excel。

六、销售汇总

选择年月查询销售额，按人员和品类分别统计，底部显示合计。

七、数据分析

选择月份查看三个图表：

  • 📅 每日销售额折线图
  • 👤 销售人员柱状图
  • 📦 产品规格饼图

八、工资管理新

工资管理共五个子栏目：

子栏目功能
📝 录入搜工人 → 搜工序自动填单价 → 填数量 → 金额自动算 → 添加。工序可从 Excel 导入
📋 记录按年月查看工资明细，点 ✅/⬜ 切换已付/未付，可筛选、编辑、撤销
📊 汇总按工人统计合计/已付/未付，底部合计；一键分享工资单、批量标记已付
👷 工人增删工人（机工/厂长/辅工）；底部是「👀 工资查看活跃度」统计
🔗 工序工序单价管理 + 规格→工序关联（基础设置），支持搜索、内联编辑、自动匹配

工人工资二维码新

  • 每个工人有长期固定二维码，扫码即打开自己的工资页面，无需登录，只显示未付款记录。
  • 汇总页「分享」可生成当月工资单链接，直接发微信给工人。
  • 管理员可在服务器生成全部工人二维码压缩包：/static/worker_qrcodes.zip。

工资查看活跃度新

统计每个工人是否扫过码查看工资，显示已查看/未查看人数及查看率，方便了解工人对工资的关注度。

九、财务管理新

功能说明
💰 财务记录按年月、责任人（下拉）、类别、收入/支出类型筛选，分页查看，导出 Excel，可撤销
📋 报账访问 /static/report.html，微信可用，支持多图上传、选择收入/支出、责任人
📂 类别添加/删除财务类别
初始余额访问 /static/init-balance.html，密钥 上山打老虎

余额公式：期初余额 + 收入 − 支出

防重复报账：相同支出/收入 + 金额 + 日期 + 类别 + 责任人，当天仅可录入一次。

十、预警阈值

全局默认阈值：低于此值触发低库存预警。

各规格颜色阈值管理：可为每个规格+颜色单独设置阈值。库存低于阈值的行会红色高亮。

十一、基础数据

模块功能
📋 规格管理添加/修改/删除产品规格（有库存的不可删）
🎨 颜色管理添加/修改/删除颜色（有库存的不可删）
👥 销售人员添加/删除销售人员（员工/渠道/电商）
📥 库存导入上传 Excel 批量导入库存，覆盖当前库存

十二、管理员

仅超级管理员可见。可查看操作日志（最近 200 条）、添加/删除管理员、重置密码。

十四、服务器运维

  • 更新代码并重启：./restart.sh
  • 数据库备份：每天凌晨 2 点自动备份到 backups/ 目录
  • 手动备份：./backup.sh
