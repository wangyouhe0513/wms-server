📦 工厂进销存管理系统 — 使用说明

一、登录与安装

打开系统网址，输入用户名和密码。默认管理员：admin / admin123

手机安装到桌面：安卓浏览器自动弹窗「添加到桌面」；苹果 Safari 打开 → 分享 → 添加到主屏幕。安装后全屏打开就像原生 App。

刷新页面：手机在顶部往下拉即可下拉刷新。

二、首页仪表盘

四张统计卡片：今日出库金额、今日入库数量、本月销售额、低库存预警。点击卡片可跳转对应页面。

快捷操作按钮可快速跳转到常用功能。

三、每日录入

快速填写（推荐）

  1. 选择 出库/入库 → 选择 销售人 → 点击 规格 → 点击 颜色 → 自动新增一行
  2. 填写数量和单价 → 点击 ✔ 提交录入

手动添加

点击「+ 出库行」或「+ 入库行」，手动输入信息。

撤销误操作

下方「今日已录入」表格，点击 ✕ 撤销 可删除错误记录并自动恢复库存。

四、实时库存

查看所有规格+颜色的当前库存，搜索框可筛选。

点击库存数字查看最近变动历史。

点击 📥 下载快照 导出带水印的库存文件。

五、出库 / 入库记录

按人员/年月查询出库或入库明细，支持导出 Excel。

六、预警阈值

全局默认阈值：低于此值触发低库存预警。

各规格颜色阈值管理：可为每个规格+颜色单独设置阈值。库存低于阈值的行会红色高亮。

七、销售汇总

选择年月查询销售额，按人员和品类分别统计，底部显示合计。

八、数据分析

选择月份查看三个图表：

  • 📅 每日销售额折线图
  • 👤 销售人员柱状图
  • 📦 产品规格饼图

九、基础数据

模块功能
📋 规格管理添加/修改/删除产品规格（有库存的不可删）
🎨 颜色管理添加/修改/删除颜色（有库存的不可删）
👥 销售人员添加/删除销售人员
📥 库存导入上传 Excel 批量导入库存

十、财务管理

功能说明
📋 报账访问 /static/report.html，微信可用，支持多图上传
💰 管理查看/筛选/导出Excel/撤销财务记录
📂 类别添加/删除财务类别
初始余额访问 /static/init-balance.html，密钥 上山打老虎

余额公式：期初余额 + 收入 − 支出

十一、工资管理

功能说明
👷 工人管理增删工人，支持机工/厂长/辅工
📏 工序单价增删工序及标准单价
📝 录入工资搜工人→搜工序自动填单价→填数量→金额自动算→添加
工序可从 Excel 导入
📊 汇总按工人统计合计/已付/未付
📋 分享一键复制工资单链接发微信，长按截图发给厂长
📥 导出按月份导出 Excel 明细+汇总

十二、管理员

仅超级管理员可见。可添加/删除管理员、重置密码、查看操作日志。

十四、服务器运维

  • 更新代码并重启：./restart.sh
  • 数据库备份：每天凌晨 2 点自动备份到 backups/ 目录
  • 手动备份：./backup.sh
