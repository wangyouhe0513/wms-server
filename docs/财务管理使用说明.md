# 财务管理 — 使用说明

## 一、首次设置

### 1. 初始化期初余额（仅需一次）
访问：`http://你的IP:8000/static/init-balance.html`

| 字段 | 说明 |
|------|------|
| 密钥 | `上山打老虎` |
| 期初余额 | 当前账上已有的现金余额 |
| 操作人 | 填写你的名字 |

提交后，财务余额 = 期初余额 + 后续收入 - 后续支出。

### 2. 设置类别（可选）
在系统左侧「💰 财务管理」→ 顶部类别标签行，输入新类别名称按回车添加，点击类别右侧 `×` 删除。

默认已包含：货款、日杂、辅料、运费、印花、布、货拉拉、其他。

---

## 二、日常报账

### 微信群成员报账
把链接发到微信群：`http://你的IP:8000/static/report.html`

报账人填写：
1. 选择 **支出** 或 **收入**
2. 填写金额
3. 选择日期和类别
4. 填写明细说明
5. 选择责任人（系统销售人员）
6. 上传凭证截图（可多选）
7. 点击提交

> 该页面无需登录，手机微信可直接打开。

### 管理员自行录入
在系统「💰 财务管理」页面查看所有记录，通过 Excel 导出了解汇总。录入仍需通过报账页面提交。

---

## 三、查看与管理

### 查看财务记录
左侧菜单 → **💰 财务管理**

- 顶部统计卡片：总收入 / 总支出 / 余额
- 选择年月筛选，点击查询
- 每条记录可点击「图1」「图2」查看凭证截图

### 导出
点击 **📥 导出CSV**（按钮文字实为导出Excel），下载 `.xlsx` 文件包含当月所有记录及汇总。

### 撤销错误记录
点击记录右侧 **✕** 按钮，确认后删除，余额自动更新。

---

## 四、余额说明

```
余额 = 期初余额 + 实际收入 - 实际支出
```

期初余额不计入收入统计，单独一行。
